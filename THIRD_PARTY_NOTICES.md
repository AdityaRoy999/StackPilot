## shadcn UI CSS variants

`frontend/src/app/shadcn-variants.css` contains `shadcn@4.3.1`'s `dist/tailwind.css`. The small style definitions are kept locally so the dashboard does not install the unrelated scaffolding CLI and its dependencies.

Source: [shadcn UI](https://github.com/shadcn-ui/ui), [published package](https://registry.npmjs.org/shadcn/4.3.1).
